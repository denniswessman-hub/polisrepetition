# Polisrepetition inför aspiranten

[Öppna träningssidan](https://denniswessman-hub.github.io/polisrepetition/)

440 frågor med facit, 20 ämnesområden och 52 fallfrågor. Träna med filter för område, lag, frågetyp och repetition. Markera egna framsteg och spara en säkerhetskopia.

Rättsläge kontrollerat **15 oktober 2026**. Publik version **1.1.0**.

## Material

- [Frågebok som PDF](pdf/Polisrepetition_infor_aspiranten.pdf)
- [Hela paketet för lokal användning](Polisrepetition_hela_paketet.zip)
- [CSV](fragor_och_svar.csv), [Anki-kort](anki_import.tsv) och [strukturerad frågebank](fragor_och_svar.json)

Frågorna är nyskrivna för repetition. Offentliga lagtexter och kunskapsstöd länkas. Kursmaterial har styrt ämnesvalet; originalfiler, interna kurslänkar och personuppgifter publiceras inte.

Detta är ett personligt studieprojekt, inte en officiell polisanvisning eller ett examinationsfacit. Kontrollera alltid tillämplig laglydelse, gärningsdag, övergångsregler och aktuella tjänsteinstruktioner i verkliga ärenden.

## Användning och integritet

Webbplatsen kräver inget konto och innehåller ingen analys- eller spårningskod. Framsteg lagras i webbläsaren. De skickas inte automatiskt till webbplatsen. GitHub Pages hanterar webbserverns trafik enligt GitHubs villkor. En ny enhet eller webbadress har separata framsteg; använd export och import för att flytta dem.

Packa upp ZIP-filen och öppna Polisrepetition.html för lokal träning. Behåll filerna och pdf-mappen tillsammans. Externa källor kräver internet.

## Publicering

Statisk webbplats utan byggsteg. GitHub Pages publicerar från `main`, rotmappen. `index.html` innehåller hela träningsappen och frågebanken. `release.json` anger version och kontrollsummor för publicerade filer.
